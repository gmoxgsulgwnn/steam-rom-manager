## 🕹️ Overview

Steam ROM Manager scans your ROM folders and adds games to Steam with cover art, screenshots, and Big Picture metadata, enabling full controller and Steam Deck support.

Whether you're a newcomer or a veteran, Steam ROM Manager provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Artwork Scraper** | Fetches covers and heroes from SteamGridDB automatically |
| **Parser Library** | Built-in parsers for RetroArch, standalone emulators, and more |
| **Steam Deck Ready** | Ideal for populating Steam Deck libraries with emulated games |
| **Batch Add** | Process thousands of ROMs in a single automated run |
